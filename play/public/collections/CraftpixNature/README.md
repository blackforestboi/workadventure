# Craftpix Nature & Ruins collection

These in-game assets were imported from the following Craftpix freebie packs supplied for this project:

- Free Forest Objects Top-Down Pixel Art
- Free Top-Down Ruins Pixel Art
- Free Top-Down Bushes Pixel Art
- Free Top-Down Trees Pixel Art
- Free Pixel Art Plants for Farm

Inventory:

- bushes: 40 placeable assets
- farm plants: 73 placeable assets
- farm supplies: 67 placeable assets
- forest: 40 placeable assets
- ruins: 40 placeable assets
- trees: 40 placeable assets

The farm sheets did not include separated PNG files. They were split into transparent, individually placeable visual components; their UI names use stable numbered variants because the source files provide no per-sprite names.

Craftpix permits use and modification in game projects, but forbids reselling or redistributing the artwork as a standalone/retrievable asset pack. Keep these files embedded in the game and do not expose an asset-download/export feature for them.
